## Features

### 📱 Feed
Infinite scroll through submissions, grid or list view. Log in for a personal feed from watched artists.

### 🔍 Search
Full-text and tag-based search with autocomplete (200K+ offline tags). Filter by rating, type, category, species, gender, sort, and date range.

### 🖼️ Post viewer
Full post card with image, artist, stats, tags, description, comments. Swipe between posts, pinch-to-zoom and pan.

### 👤 Profiles & watchlist
Artist profiles with gallery, favorites, watching & watchers. One tap to favorite or watch.

### ⬇️ Downloads
Save images with metadata to a dedicated section.

### 🔒 Content filters
Mute words in titles, toggle NSFW on/off.

### 🎨 Customization
8 color themes, 8 app icon styles, 3 languages (EN/RU/UA), glassmorphism UI with blur effects.
